Student: Alina Ibadulla  
Course: WEB Technologies 1 (Front End)
Project title: My First Webpage  

Objective:
The goal of this laboratory work is to learn and practice the fundamental building blocks of web development:
- Structuring content using HTML5 elements.
- Styling elements and building layout architecture using CSS3.
- Publishing a static site using GitHub Pages.

Step-by-Step implementation -

Part 1 & 2: HTML fundamentals & Intermediate elements
1. Boilerplate & Text structure: Created `index.html` with standard boilerplate. Structured personal details using headings `<h1>` to `<h3>` and regular paragraphs.
2. Lists & Links:
- Ordered list to showcase my hobbies.
- Unordered list with external clickable links leading to my favorite platforms.
3. Media & Buttons: Linked a profile picture using `<img>` and added an interactive button.
4. Data tables:
- Created a weekly class schedule using HTML table tags - `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>`
- Implemented a two-column table layout menu as an extra structure challenge.
5. Interactive form: Developed a user input form containing `text`, `email`, and `color` inputs along with a submission button.
6. Emojis: Added emojies within text paragraphs.

Part 3 & 4: CSS Styling & Layout techniques
1. CSS integration: Combined inline styles (`style="..."`), Internal CSS (`<style>` in `<head>`), and Linked External stylesheet (`style.css`).
2. Selectors: Applied styles using:
- Element selectors (`h1`, `p`, `table`) for global formatting.
- Class selectors (`.highlight`, `.main-content`, `.btn`) for reusable styling.
- ID selectors (`#main-heading`) for unique main element styling.
3. Box model & sizing: Managed element dimensions, borders, internal padding, and external margins. Used relative (`%`, `em`, `rem`) and absolute (`px`) length units.
4. Layout & positioning:
- Formatted structural divisions (`<div class="header-section">`, `.main-content`, `.footer-section`).
- Demonstrated CSS Positioning states (`static`, `relative`, `absolute`).
- Built a multi-column flow using `float: left/right` cleared with `clear: both`.
5. Favicon: Added site icon metadata via `<link rel="icon">`.
